A browser opening the dashboard for the first time shows a code; approve it here if the code matches and that browser gets the API key below. A kiosk tablet shows a code too when someone wants to change its settings.

API key

…

Create one at my.homey.app → Settings → API Keys and tick these boxes, the indented ones only:

  • Devices: View devices, Control devices
  • Flows: View Flows, Start Flows
  • Moods: View Moods, Set Moods
  • Variables: View Variables
  • Zones: View Zones
  • Notifications: View Notifications
  • Apps: View Apps
  • Users: View Users, Edit Self User
  • Logs: View Logs
  • Presence: your own presence
  • System: View System
  • Location: View Location
  • Dashboards and Energy: their View box

Leave the group boxes themselves (Devices, Flows, …) and Homey unticked: they also allow deleting and changing things, and every paired browser holds this key. After saving, this page names anything missing or too broad. Paired browsers keep a copy of the key: to sign them all out, delete it in my.homey.app and save a new one here.
